# Calculate-BMI
Calculate BMI adalah aplikasi sederhana berbasis Python yang digunakan untuk menghitung Body Mass Index (BMI) berdasarkan berat badan dan tinggi badan. Aplikasi ini membantu pengguna mengetahui apakah berat badannya termasuk kategori kurus, normal, overweight atau obesitas.

# Fitur
•	Input berat badan dan tinggi badan  
•	Perhitungan BMI otomatis menggunakan Python  
•	Menampilkan nilai BMI  
•	Menampilkan kategori BMI berdasarkan standar kesehatan  

# Cara menjalankan 
1. Install Python
2. Download atau clone repository ini
3. Jalankan file python menggunakan terminal atau VS Code
